# p2p-cdn
P2P Universal CDN adalah pure-script SDK berbasis WebRTC &amp; Cache API untuk hemat bandwidth server hingga 80%. Mencegat otomatis semua file (gambar, video, PDF, ZIP) dari browser. Jika ada peer, file ditransfer antar-pengunjung. Jika tidak ada, ditarik dari server lalu disimpan di cache lokal (0 ms).
